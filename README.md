# Rooccoliano_vector toolz

An experimental kinetic typography and vector pattern web tool.

## Run
Open `index.html` in a modern browser, or publish it using GitHub Pages.

## Publish using GitHub Pages
1. Create a public GitHub repository.
2. Upload `index.html` to the repository root on the `main` branch.
3. Go to **Settings → Pages → Build and deployment**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Visit `https://YOUR_USERNAME.github.io/YOUR_REPO/` after deployment.

## Notes
- SVG text is not converted into paths; recipient machines may need the corresponding typeface.
- PDF export uses the browser Print dialog.
- Imported fonts may be subject to license restrictions.
